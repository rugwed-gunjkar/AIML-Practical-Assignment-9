# AIML Practical Assignment No. 9

## Title
Implement and Evaluate a Bayesian Classifier on the IRIS Dataset and Analyse Performance Using Accuracy, Confusion Matrix, Precision and Recall.

## Objective
To implement a Gaussian Naive Bayes classifier on the Iris dataset and evaluate its performance using accuracy, confusion matrix, precision and recall.

## Tools and Technologies
- Python
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- VS Code

## Dataset
The Iris dataset is loaded using `load_iris()` from Scikit-learn. It contains three flower classes:
- Setosa
- Versicolor
- Virginica

## Algorithm
Gaussian Naive Bayes is used for classification. The dataset is divided into training and testing sets. The model is trained using the training data and evaluated using the testing data.

## Evaluation Metrics
1. Accuracy
2. Confusion Matrix
3. Precision
4. Recall
5. F1-Score

## Result
The Gaussian Naive Bayes classifier successfully classifies the Iris flower species. Its performance is evaluated using accuracy, confusion matrix, precision, recall and F1-score.

## Conclusion
The experiment demonstrates that Gaussian Naive Bayes is an efficient classification algorithm. It performs well on the Iris dataset and provides a simple probabilistic approach to classification.
